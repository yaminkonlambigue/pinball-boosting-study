# Pinball boosting: replication and extensions

Replication of the Monte Carlo study and application of Bauer, Haupt & Linner
(QR-QR.Boost / QR-LS.Boost), followed by new experiments.

## Reference code
Included as a git submodule in `external/pinball_boosting`.
- Source: https://github.com/stefanlinner/pinball_boosting
- Pinned commit: 0b25e90de05cbea6bd5b7abc5eb19d9ce8c8d71c

## Cloning this repository
    git clone --recurse-submodules <url>
If `external/` is empty: `git submodule update --init`.
